# Как обновлять моды и лаунчер

Лаунчер читает `manifest.json` из этого репозитория (репозиторий должен быть **публичным**).
Файл создаётся автоматически — руками его править не нужно.

## Обновить моды
1. Положите/замените/удалите `.jar` в папке `mods/`.
2. `git add . && git commit -m "mods" && git push`.
3. GitHub Actions сам пересоберёт `manifest.json` (вкладка Actions → Update launcher manifest).
   Локально то же делает `python tools/make_manifest.py`.
4. У игроков кнопка вместо «თამაში» станет «ჩამოტვირთვა» — лаунчер докачает новые моды и удалит убранные.
   (GitHub кэширует файлы ~5 минут — изменения доходят с небольшой задержкой.)

## Сменить версию Forge
Измените `"forge"` в `tools/config.json` (например `47.4.0`) и запушьте. Версия должна совпадать с серверной.

## Обновить сам лаунчер
1. В `pom.xml` поднимите `<version>` (например 0.1.0 → 0.1.1).
2. `mvn clean package` → получится `target/MythosLauncher.jar`.
3. Положите его в `launcher/MythosLauncher.jar` в этом репозитории и сделайте push.
4. Action запишет новую версию и sha256 в `manifest.json`. При следующем запуске лаунчера
   у игрока он сам скачает jar, заменит себя и перезапустится.
Версия читается из самого jar — отдельно нигде вписывать её не надо.

## Ограничения GitHub
Файл не больше 100 МБ (лучше до 50 МБ). Git LFS не подходит — лаунчер качает файлы напрямую.

## Файлы игры (config, картинки FancyMenu, ресурспаки)
Всё, что лежит в папке `game_files/`, лаунчер копирует в папку игры с тем же путём:
`game_files/config/fancymenu/assets/x.png` → `~/.mythos-launcher/game/config/fancymenu/assets/x.png`.
Файл удалили из `game_files/` — лаунчер удалит его и у игроков. Так же работает с `config/`, `resourcepacks/` и т. д.
